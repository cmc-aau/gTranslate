gtranslate.log
==============

The console output of gTranslate saved to disk. It is written to the output directory as ``gtranslate.log``
(regardless of ``--prefix``) by commands with an ``--out_dir`` argument. Output from subsequent runs in the same
output directory is appended to the file.
